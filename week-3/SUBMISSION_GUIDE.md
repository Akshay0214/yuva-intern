# Week 3 Submission Guide

## Deliverable

Submit the ZIP containing:

1. `buggy-version/` - intentionally flawed code used for the debugging exercise.
2. `fixed-version/` - corrected implementation.
3. `DEBUGGING_REPORT.md` - debugging methodology and resolution details.
4. `BUG_TRACKING_TABLE.md` - bug summary.
5. `TEST_CASES.md` - test plan.
6. `POSTMAN_TESTING.md` - manual testing instructions.
7. `README.md` - project setup.

## Before Submission

Run the fixed project locally, configure MongoDB, install dependencies and execute:

```bash
npm test
```

Capture screenshots of actual execution. Do not claim a benchmark number unless you actually measured it.

For a college/internship report, include:
- project overview
- debugging methodology
- bug-by-bug analysis
- before/after code screenshots
- test screenshots
- final test results
- conclusion
